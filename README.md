# Rhience R. Asuncion — Virtual Assistant & CX Portfolio

A complete, responsive static portfolio website ready for **GitHub Pages**.

## Included Files
- `index.html`
- `styles.css`
- `script.js`
- `README.md`
- `assets/profile.jpg`

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all extracted files (`index.html`, `styles.css`, `script.js`, `README.md`, and `assets/profile.jpg`) to the repository root.
3. Go to **Settings -> Pages**, choose **Deploy from a branch** (`main` / `/ (root)`), and save.
