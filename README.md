# Rhience R. Asuncion — Virtual Assistant & CX Portfolio

Ready-to-upload static website for **GitHub Pages**.

## Files Included
- `index.html`
- `styles.css`
- `script.js`
- `README.md`
- `assets/profile.jpg` (place your profile photo at `assets/profile.jpg`)

## Deploy on GitHub Pages
1. Extract the ZIP folder so `index.html`, `styles.css`, `script.js`, `README.md`, and `assets/` are visible.
2. Upload those files into your GitHub repository root (not the `.zip` file itself).
3. Go to **Settings -> Pages**, select **Deploy from a branch** (`main` and `/ (root)`), and save.
